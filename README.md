# Horizonte Pessoal — Site de Projeto de Vida

Projeto web desenvolvido em **HTML5**, **CSS3** e **JavaScript puro**, estruturado para ser aberto e editado diretamente no **Visual Studio Code (VS Code)**.

## Estrutura de Pastas

```text
site-projeto-de-vida/
├── index.html       # Estrutura principal da aplicação
├── css/
│   └── style.css    # Estilos responsivos e layout de impressão (PDF)
├── js/
│   └── script.js    # Lógica da Roda da Vida, metas e salvamento local
└── README.md        # Instruções de uso
```

## Como executar no VS Code

1. Extraia o arquivo `.zip` em uma pasta no seu computador.
2. Abra o **VS Code**, clique em **Arquivo > Abrir Pasta...** (`File > Open Folder...`) e selecione a pasta extraída.
3. Para visualizar o site:
   - Instale a extensão **Live Server** (de Ritwick Dey) no VS Code e clique em **Go Live** no canto inferior direito; **ou**
   - Dê um duplo clique diretamente no arquivo `index.html` para abri-lo no seu navegador padrão.
